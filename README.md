# SBA301_Ass2

Dự án nằm trong [A2HoangTLT_SBA](A2HoangTLT_SBA/README.md), với cấu trúc:

```text
A2HoangTLT_SBA/
├── backend/
├── frontend/
└── scripts/
```

Chạy frontend từ thư mục `Ass2`:

```powershell
cd .\A2HoangTLT_SBA\frontend
npm run dev
```

Chạy backend bằng Windows Authentication từ thư mục `Ass2`:

```powershell
.\A2HoangTLT_SBA\scripts\Start-Backend.ps1
```

Xem [hướng dẫn đầy đủ và tài khoản mẫu](A2HoangTLT_SBA/README.md).
